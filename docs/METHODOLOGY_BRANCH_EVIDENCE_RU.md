# Методика доказательного дашборда зарубежных филиалов МГИМО

Дашборд использует один основной индекс, без альтернативных режимов. Пользователь может изменить веса семи факторов и проверить устойчивость рейтинга самостоятельно. При этом сами значения факторов не являются экспертными оценками стран: они рассчитываются из официальных или проверяемых статистических показателей по единой формуле для всех стран.

## Семь факторов

1. Рыночный потенциал.
2. Программно-отраслевая релевантность.
3. Нормативно-партнёрский контекст.
4. Экономическая среда.
5. Финансовая реализуемость.
6. Операционная реализуемость.
7. Кадрово-стратегическая значимость.

Каждая вкладка страны должна раскрывать фактор до уровня: первичный показатель → год → исходное значение → нормировка → вес → вклад в фактор.

## Вьетнам

Вьетнам отображается в общем рейтинге со статусом «В подготовке». Этот статус не даёт бонуса к итоговому индексу и не исключает страну из общего списка. Если Вьетнам занимает первое место по расчётам, это интерпретируется как независимое подтверждение статистической привлекательности страны.
