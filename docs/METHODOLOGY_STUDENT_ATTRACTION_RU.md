# Методика SAI_MGIMO_V3

`SAI_MGIMO_V3` - самостоятельный индекс стран для привлечения иностранных студентов в МГИМО в Москве. Он не является моделью открытия зарубежных филиалов, не использует финансовую модель набора студентов в филиал и не строит фактические потоки студентов без открытого странового источника.

Итоговый индекс рассчитывается по одной формуле:

```text
SAI = 100 * (
  0.50 * A_YOUTH_OPPORTUNITY
+ 0.16 * A_OUTBOUND_MOBILITY_UIS
+ 0.12 * A_LEGAL_PARTNERSHIP_CONTEXT
+ 0.08 * A_PROGRAM_RELEVANCE
+ 0.06 * A_AFFORDABILITY_ACCESS
+ 0.04 * A_DIGITAL_REACH
+ 0.04 * A_DATAQ
)
```

Жесткие фильтры применяются отдельно: недружественные государства по официальному перечню, Россия как внутренний рынок и специальные/несамостоятельные территории не получают студенческий индекс и место в рейтинге.

## Компоненты

- `A_YOUTH_OPPORTUNITY`: размер и динамика молодежной когорты 15-24 по UN WPP 2024.
- `A_OUTBOUND_MOBILITY_UIS`: официальный UIS outbound mobility ratio, dataset `uis006`, indicator `MOR.5T8.40510`.
- `A_LEGAL_PARTNERSHIP_CONTEXT`: официальные правовые и партнерские ограничения.
- `A_PROGRAM_RELEVANCE`: программно-отраслевая релевантность из открытых индикаторов.
- `A_AFFORDABILITY_ACCESS`: доступность через GDP per capita PPP.
- `A_DIGITAL_REACH`: доля пользователей интернета по WDI.
- `A_DATAQ`: полнота обязательных доказательных строк.

Страна без строки UIS или другого обязательного источника не получает SAI score и практическое место. Вес не перераспределяется.

## Источники

Демография строится из UN WPP 2024. UIS-компонент загружается из UNESCO DataHub. Экономика и цифровой доступ берутся из World Bank WDI. Нормативные ограничения берутся из официального перечня недружественных государств и территорий и справочников МГИМО.

Фактические страновые данные МГИМО по студентам показываются только при наличии открытого странового источника. Визуальные стрелки направлений по индексу показывают модельный потенциал, а не численность студентов.
